# 💫 About Me
I'm a third-year B.Tech Computer Science student at Vellore Institute of Technology, Vellore, with an interest in software engineering, systems programming, and machine learning.

I enjoy understanding the fundamentals behind the technology I work with, from operating systems, networking, and data structures to backend architecture and machine learning models. I like building projects end to end, taking ideas from system design and database modelling to API development, frontend implementation, and model integration.

My experience spans C++, Java, Python, JavaScript, React, Node.js, MongoDB, and computer vision tools. I'm particularly interested in writing efficient, maintainable code and exploring how software systems work beyond the surface level.

Always learning, building, and exploring new challenges.
